# Спецификация кинематических стилей и аудиореактивного маппинга
## Проект: Spectromorphology Visualizer (Mandala & Ribbons)

Документ фиксирует художественные и физические паттерны поведения кистей для последующей привязки к аудиоанализатору (Web Audio API: FFT, RMS, Beat Detection, Spectral Flux).

---

## 1. Ключевая эстетическая находка (Morphology & Geometry)

В ходе тестирования кинематики выявлена фундаментальная зависимость геометрии рисунка от связки трёх параметров:
1. `waveAmplitude` (`waveAmp`) — амплитуда пространственной синусоиды вдоль пути [0..10].
2. `waveFrequency` (`waveFreq`) — пространственная частота синусоиды [1..10].
3. `minTurnRadius` — минимальный физический радиус поворота агента ($R_{\min} = v / |\omega_{\max}|$) [0..0.5].

### 💎 Стилевые архетипы формы:

| Стиль / Архетип | Параметры | Визуальный образ | Музыкальный контекст |
|---|---|---|---|
| **«Кристалл / Кубизм / Угловатый стиль»** | **Min `minTurnRadius` (0.02–0.08)**<br>**Min `waveAmplitude` (0.0–1.2)** | Мандала становится **квадратной**, граненой, кристаллической. Кисть делает резкие ортогональные изломы и острые грани. Исчезает рыбья плавность, появляется техногенная чёткость. | Индастриал, IDM, Glitch, резкие хэты/снейры, техно, перкуссия, бит-дропы. |
| **«Жидкий шёлк / Органика / Медуза»** | **High `minTurnRadius` (0.25–0.45)**<br>**High `waveAmplitude` (4.0–8.0)** | Плавные, текучие, шелковистые траектории. Округлые лепестки, биоморфная мандала, отсутствие острых углов. | Эмбиент, пэды, струнные, суб-бас, плавные вокальные партии, чиллаут. |
| **«Полое ядро / Корона / Отрицательное пространство»** | **Max `minTurnRadius` (0.40–0.50)** | **Линии физически не могут попасть в центр.** Ядро мандалы остаётся кристально чистым, образуя пустое круглое «око бури» (Negative Space Core), а штрихи выстраиваются в широкое внешнее кольцо/венец. | Пространственные интро/аутро, чистые вокальные соло, паузы перед дропом, моменты «разрежения» микса, когда центру композиции нужен воздух. |
| **«Каллиграфическая вязь / Филигрань»** | **Medium `minTurnRadius` (0.12–0.18)**<br>**High `waveFrequency` (6.0–9.0)**<br>**Medium `waveAmplitude` (2.5–4.0)** | Кружевные, тонкие восточные узоры, волнообразнаяCalligraphy-текстура, кружевные арабески. | Синтезаторные арпеджио, гитарные переборы, высокая плотность нот (16-е доли). |

### 📐 Закон согласованности толщины и радиуса поворота (Thickness-Radius Coupling Law):
> **«Если ширина кисти большая, то и минимальный радиус поворота должен быть большой: $R_{\min} \ge \frac{W}{2}$»**
* **Геометрическая причина**: лента имеет толщину $W$. Радиус её внутреннего края при вираже равен $R_{\text{inner}} = R_{\text{center}} - \frac{W}{2}$. Если $R_{\text{center}} < \frac{W}{2}$, внутренний край выворачивается наизнанку, образуя уродливую складку-залом («перочинный нож») и самопересечение геометрии.
* **Каллиграфический принцип**: широкий массивный штрих (мощный бас) органично смотрится только на широких, размашистых, величественных дугах. Попытка согнуть толстую кисть на пятачке превращает штрих в бесформенную кляксу.
* **Правило для звука**: при нарастании энергии баса (Kick/Sub), когда кисть наливается толщиной ($W \uparrow$), минимальный радиус поворота $R_{\min}$ автоматически пропорционально подтягивается вверх. Тонкая же кисть ($W \downarrow$) освобождается для микроспиралей и резких кристалловидных изломов.

## 2. Архитектура связки со звуком (Audio Reactive Mapping Plan)

При подключении аудио-движка (AudioContext / AnalyserNode) параметры кистей разделяются на три частотных диапазона:

### Низкие частоты (Low / Bass / Kick / Sub)
* **Амплитуда дыхания толщины (`maxWidth`, `strokeWidthLimit`)**:
  * Мощный удар бочки (Kick) $\implies$ импульсный всплеск толщины мазка (до 10.0), сочный чернильный отпечаток.
  * Затухание баса $\implies$ сужение кисти до тонкой волосяной линии.
* **Масштаб и зум (`uZoom`)**:
  * Саб-басовые вибрации создают мягкую оптическую пульсацию всего полотна мандалы.

### Высокие частоты (Highs / Transients / Snare / Hats / Percussion)
* **Кристаллический переход (Форма траектории)**:
  * На резких транзиентах (хэты, клики, снейр) $\implies$ динамический спад `minTurnRadius` до $0.03$ и сброс `waveAmplitude` до $0.0$.
  * Результат: на акцентированных битах мандала мгновенно «схлопывается» в кристаллическую квадратную форму с острыми гранями.
* **Раздвоение кисти (`triggerSplit`)**:
  * Резкий сплеш/снейр при тонкой кисти провоцирует срыв потока — немедленное раздвоение кисти на две головы.

### Средние частоты (Mids / Leads / Vocals / Arpeggio)
* **Пространственная частота (`waveFrequency`)**:
  * Мелодический рисунок управляет частотой синусоидального виляния вдоль траектории.
* **Скорость движения (`speedMultiplier`)**:
  * Энергетическая плотность трека плавно разгоняет или замедляет полет кистей.
* **Дыхание ядра / Очистка центра (`minTurnRadius` dynamic modulation)**:
  * Повышение `minTurnRadius` до максимума (0.45–0.50) вытесняет кисти из центра, оставляя пустое «око бури» для вокала или солирующего инструмента.
  * Снижение `minTurnRadius` до 0.05–0.12 позволяет мазкам нырять прямо в центр, создавая плотные центральные розетки и узлы.

## 3. Математические формулы для будущей интеграции

```javascript
// Пример реактивного обновления в цикле рендера:
function updateAudioReactiveKinematics(audioFeatures, ribbon) {
  const { bassEnergy, highTransient, midRms } = audioFeatures;

  // Квадратизация мандалы на резких перкуссионных звуках:
  const crystallize = highTransient; // [0..1]
  ribbon.minTurnRadius = THREE.MathUtils.lerp(0.20, 0.03, crystallize);
  ribbon.waveAmp       = THREE.MathUtils.lerp(0.028, 0.002, crystallize);

  // Каллиграфическая частота от плотности середины:
  ribbon.waveFreq = THREE.MathUtils.lerp(2.5, 7.5, midRms);

  // Толщина от энергии баса:
  ribbon.widthLimit = THREE.MathUtils.lerp(0.015, 0.080, bassEnergy);
}
```
